1. CRITICAL PERFORMANCE PROBLEM

Independent uncached live requests showed:

- Homepage response times of approximately 5–11.3 seconds.
- Average response time across 78 sitemap URLs: approximately 11.52 seconds.
- Slowest response: approximately 15.45 seconds.

Investigate and fix the actual server-side cause. Do not hide the issue with a loading animation.

Check for:

- Database or storage calls occurring on every public request.
- Authentication/session initialization on public pages.
- Dashboard, admin or private-service initialization leaking into public routes.
- Dynamic sitemap or content generation on every request.
- Blocking external API calls.
- Server-side analytics or consent initialization.
- Repeated content transformations.
- Unnecessary middleware.
- Poor route caching.
- Cold-start-heavy application architecture.
- Oversized server bundles.
- Duplicate requests or initialization.
- Pages being rendered dynamically when they can be statically generated.

Required performance changes:

- Public calculator, category, guide and policy pages should not require database access to render.
- Pre-render or statically generate public content wherever safe.
- Cache stable public HTML appropriately.
- Cache static images, fonts, CSS and JavaScript using long-lived immutable caching where filenames are fingerprinted.
- Keep sitemap.xml and robots.txt lightweight.
- Do not apply private/no-cache settings to stable public pages without a real reason.
- Preserve correct consent and calculator behaviour.
- Do not cache personalized or private routes publicly.
- Add safe performance instrumentation or timing logs in development if needed, but remove noisy debugging before completion.

After fixing, run repeated production-equivalent tests, including a cold request and multiple warm requests. Report TTFB and total response time separately.

- Warm server response/TTFB preferably under 500 ms.
- Normal total HTML response preferably under 1 second.
- Cold requests should be materially faster than the current 5–15 seconds.
