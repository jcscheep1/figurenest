---
name: Integer-factor intent consolidation
description: Canonical-route decisions for overlapping factor, GCF, GCD, HCF, and prime-factorization search intents.
---

Treat Common Factor, Greatest Common Factor, GCF, GCD, and HCF as one multi-mode calculator intent with one canonical route. Treat Factor and Prime Factorization as one multi-mode calculator intent with one canonical route.

**Why:** Separate pages would substantially duplicate the same integer inputs, explanations, and algorithms and would create search-intent cannibalization. Multi-mode pages fully cover the narrower synonyms while keeping the distinction between shared factors and one-number factorization clear.

**How to apply:** Add synonym-rich search tags and visible explanations to the consolidated pages rather than publishing alias pages. Keep LCM separate because it answers a different divisibility question.
