name: FigureNest tool counting
description: Defines the non-obvious boundary between directory tools and the broad Unit Converter hub.
---

FigureNest’s public discovery total is 162 standalone tools: 154 calculator routes and 8 focused converter routes. The broad Unit Converter remains a useful, indexable route with its own canonical, but is a converter hub and does not add another tool to directory or category totals.

**Why:** Counting every indexable calculator-like route produced a misleading 163 total because the all-in-one Unit Converter summarizes conversion families already represented by focused converter destinations.

**How to apply:** Derive homepage, directory, API catalogue, and category totals from the discovery collection. Preserve the Unit Converter route in indexable-route, sitemap, internal-link, and metadata validation.
